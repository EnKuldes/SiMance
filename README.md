# SiMance

This is an app made by my teammate (Fadel)[https://github.com/ridlafalah] and we working on 2020. General purpose of this app is to generate perfomance dashboard and make reconcilation report for each of divisions available. This app involve human resources team to upload perfomance of employee, employee records (such as their personal ID, etc) and verify reconcilation reports is justified. 

This app use TALL Stack (Tailwind, Alpine, Laravel and Livewire) which is using new tech than we have ever use before, and MySQL/MariaDB for RDBMS.
